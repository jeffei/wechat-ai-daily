EMBODIED AI WEEKLY / 具身智能周报

具身智能前沿观察

2026年10月25日 · 全球具身智能情报精选

SIGNAL / 本周风向标

本周具身智能行业展现出明显的工程落地与基础模型齐头并进趋势。一方面，Agility Robotics发布Digit 5、特斯拉开启Optimus加州产线，加速人形机器人硬件规模化制造；另一方面，以Eka Robotics的VFA力控模型、Dream Labs的跨本体Dream API及Daimon Robotics的触觉智能为代表，感知、力控与跨硬件泛化等物理AI模型底座正吸引巨额资本重金押注。

01 / 本周焦点 · 重大突破

BRIEF 01.01

Agility Robotics正式发布Digit 5人形机器人，剑指规模化实用作业

从俄勒冈州立大学机器人实验室孵化成立的Agility Robotics正式发布全新一代人形机器人Digit 5。

官方表示，Digit 5旨在成为首款能够安全、经济且规模化执行实用任务的人形机器人，目标是推动数万台人形机器人进入实际应用场景。

影响解读

Digit 5的亮相标志着头部人形机器人企业正全力跨越从样机展示到经济型规模化量产的门槛，实用性和成本控制成为现阶段产品迭代的核心标准。

信息来源：IEEE Spectrum Robotics

BRIEF 01.02

特斯拉在加州启动Optimus人形机器人生产，持续加码AI与自动化研发

最新财报显示，特斯拉在营业收入持平且利润下滑43%的压力下，大幅增加了研发支出。

在此背景下，特斯拉已在加利福尼亚州正式启动Optimus人形机器人的产线制造，坚定按下在机器人、人工智能和自动驾驶领域的加速键。

影响解读

特斯拉将利润压力转化为对Optimus量产的坚定投入，反映出头部科技巨头将具身智能视作下一代增长曲线的核心赌注，这也将直接刺激全球人形机器人产业链供应链的提速。

信息来源：TechCrunch Robotics

02 / 头部玩家 · 产品与融资

BRIEF 02.01

物理AI初创企业Eka Robotics估值达14.5亿美元，斩获1.5亿美元新融资

Eka Robotics宣布完成1.5亿美元融资，投后估值达到14.5亿美元，凭借其研发的物理AI模型在业界引发广泛关注。

该公司正在构建名为“视觉-力-动作”（VFA）的全新模型，旨在通过大规模强化学习让机器人掌握物理直觉，其机械臂在多样化物体抓取上表现出高度拟人化的平滑性。

影响解读

纯视觉大模型在物理交互中的局限性正催生新一代多模态物理交互底座，融入高精度力控反馈的物理AI模型已成为资本与行业评估具身智能技术深度的新标杆。

信息来源：The Robot Report

BRIEF 02.02

Dream Labs完成9000万美元融资并推出跨硬件架构Dream API

机器人AI研发机构Dream Labs宣布完成9000万美元融资，并同步推出Dream API开发接口。

据介绍，其核心AI模型Dream-1能够支持跨厂商、跨本体的机器人硬件系统，并实现机器人跨场景学习能力的迁移与共享。

影响解读

跨本体通用模型与API工具的兴起，有望降低具身智能软件的开发与泛化门槛，为多厂商机器人协同与技能复用铺平底层通路。

信息来源：The Robot Report

BRIEF 02.03

Daimon Robotics打造触觉智能基础设施层，提升物理作业可靠性

Daimon Robotics公布其围绕具身智能触觉感知的基础设施方案。

该团队将触觉感知、真实世界数据采集、仿真系统与AI大模型打通，致力于帮助机器人更稳定可靠地应对真实环境中的复杂物理交互任务。

影响解读

除视觉外，高精度触觉与物理力学数据的闭环是实现细粒度具身操作不可或缺的一环，专用触觉基座方案将加速高难度装配及交互任务的算法迭代。

信息来源：The Robot Report

03 / 落地应用 · 商业进展

BRIEF 03.01

农业装备巨头AGCO与Agility达成协议，将在堪萨斯工厂引入Digit人形机器人

农业设备制造商AGCO宣布将引入Agility Robotics旗下Digit人形机器人开展试点应用。

该试点项目预计将于2027年正式启动，部署地点位于AGCO设在堪萨斯州的农业装备生产工厂。

影响解读

工业重型装备制造场景的复杂装配与搬运需求，正成为检验人形机器人真实工业适配度的试验田，商业化场景正从仓储物流向更复杂的工业智造纵深演进。

信息来源：The Robot Report

BRIEF 03.02

Gecko Robotics获美国海军3亿美元大额合同，工业检测机器人深入核心领域

自动化检测与机器人企业Gecko Robotics宣布与美国海军签署一项价值3亿美元的业务合同。

Gecko方面表示，该长期订单表明美国军工部门对其机器人交付成果与核心防务能力的认可。

影响解读

具备严苛工况作业能力的特种检测机器人已进入高壁垒、高价值的商业化变现深水区，展现了具身检测技术在国防基础设施维护上的扎实价值。

信息来源：The Robot Report

BRIEF 03.03

林业机器人初创公司Kodama完成700万美元融资，通过远程操作与数据飞轮推进伐木自动化

聚焦林业与采伐设备自动化的机器人公司Kodama宣布完成700万美元融资。

该公司现阶段以远程遥控作业作为切入点，在实际林业操作中积累关键交互数据，以此逐步构建自动化作业能力。

影响解读

在复杂野外非结构化环境中，采用“人机协同遥控-积累物理交互数据-推进自主化”的渐进式商业路径，为极端特种垂直行业的具身落地提供了实用范例。

信息来源：The Robot Report

04 / 主编锐评

EDITOR'S PERSPECTIVE

观察本周的产业风向，具身智能赛道正呈现出清晰的“物理交互深化”与“工程制造落地”两大轴线。在硬件层面，特斯拉在财务承压之下依然全面开启Optimus加州产线，Agility Robotics则以高性价比和规模化为首要目标推出Digit 5。事实表明，第一梯队人形机器人企业已从单纯追求运控演示，转向直面产线节拍、良率与单位经济效益的工程化制造深水区。

在技术与模型架构层面，Eka Robotics凭借视觉-力-动作（VFA）模型跻身独角兽行列，以及Daimon Robotics对触觉基础设施的构建，清晰地释放出一个信号：仅依赖高维纯视觉生成在真实物理世界中的鲁棒性仍有天花板，融合精准力控与触觉反馈的物理AI底座正成为具身智能下半场的核心护城河。谁能率先攻克泛化力控并构建跨本体的软硬件闭环，谁就将真正主导智能物理实体的规模化爆发。
